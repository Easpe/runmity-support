Garmin Connect IQ Data Field

Make passing runners
feel a little friendlier.

Runmityは、近くの利用者同士がラン中に気軽な挨拶を交わすきっかけを作る、実験的なGarmin Data Fieldです。

初期設定

  1. Connect IQ StoreからRunmityをインストールします。
  2. Garminの「ラン」アクティビティを開き、1項目のデータ画面にRunmityを追加します。
  3. もう1台の対応ウォッチでもRunmityを追加し、ランを開始して送信状態にします。
  4. System 8端末では「センサーとアクセサリー」から「Runmity 近くのランナー」を追加します。
  5. ラン設定の「アラート」→「Connect IQ」でRunmityを有効にし、双方でランを開始します。
初回版の制約: System 8端末の初回センサー登録には、Runmityを実行中の別の対応ウォッチが近くに必要です。単独の最初の利用者は登録を完了できません。

How to set up

  1. Install Runmity from the Connect IQ Store.
  2. Add Runmity to a one-field data screen in the native Run activity.
  3. On a second supported watch, add Runmity and start Run so it is transmitting.
  4. On a System 8 watch, add “Runmity Nearby” under Sensors & Accessories.
  5. Enable Runmity under Run Settings → Alerts → Connect IQ, then start Run on both watches.
First-release limitation: Initial sensor registration on System 8 requires another compatible watch nearby and actively running Runmity. A solo first adopter cannot complete registration.

No account

アカウント、スマートフォン、位置情報、インターネット接続、バックエンドは使用しません。

Activity-scoped

匿名の短期IDはアクティビティごとに生成し、ラン終了時に破棄します。

Local stats

対応端末では日別のGreetingイベント数、ストリーク、累計だけをウォッチ内に保存します。

Safety and expectations

振動と表示は任意の挨拶の合図です。相手の身元、正確な距離、安全、物理的なハイタッチの成立を示すものではありません。周囲と走路の安全を優先し、反応が難しい場合は通知を無視してください。

The vibration and artwork are optional greeting cues. They do not identify another person or guarantee distance, safety, or physical contact. Always prioritize your route and surroundings.
