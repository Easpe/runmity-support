Garmin Connect IQ Data Field

Make passing runners
feel a little friendlier.

Runmityは、近くの利用者同士がラン中に気軽な挨拶を交わすきっかけを作るGarmin Connect IQデータ項目です。

できること

ラン中に、ハイタッチのきっかけを。

双方のウォッチがRunmityを検知すると、専用の振動と全画面のハイタッチアニメーションでお知らせします。同じ相手へのGreetingは1回のランにつき1回だけです。

必要なもの

対応ウォッチが2台

Greetingには双方のウォッチへのインストールが必要です。センサー登録が必要な機種では、最初の登録時にもRunmityを実行中の別の対応ウォッチを使用します。

Device guide

対応機種と設定の違い

対象機種最初のセンサー登録統計画面
Forerunner 55、245（非Music）不要なし（軽量版）

重要: 「必要・初回のみ」の機種は、Runmityを実行中の別の対応ウォッチが近くにないとセンサー登録を完了できません。単独の最初の利用者は登録できません。

Initial setup

初回設定

1

RunmityをRun画面へ追加（全機種）

  1. Connect IQ StoreからRunmityをインストールします。
  2. GarminのRunアクティビティで、1項目のデータ画面にRunmityを追加します。

Forerunner 55

UPを長押し → アクティビティ＆アプリ → ラン → ラン設定 → トレーニングページ → 追加 → カスタムデータ → 1項目 → データ項目 → Connect IQ → Runmity

Forerunner 570

ランを開く → ラン設定 → データ画面 → データ項目を編集 → Connect IQ → Runmity

その他の機種では、「トレーニングページ」または「データ画面」内のConnect IQデータ項目からRunmityを選びます。名称は機種や言語設定により異なる場合があります。

2

最初のセンサー登録（対象機種のみ・1回だけ）

上の表で「必要・初回のみ」となっている機種だけ実施します。

  1. 別の対応ウォッチでもRunmityをRun画面に追加し、先にRunを開始します。
  2. 登録するウォッチで「センサーとアクセサリー」→「新規追加」→「Connect IQ」を開きます。「Connect IQ」がない場合は「すべて検索」を選びます。
  3. 最大30秒待ち、「Runmity 近くのランナー」を選択して登録を完了します。

Forerunner 55、245／245 Music、745、945／945 LTEではこの手順を飛ばしてください。

3

Greetingアラートを有効化（全機種）

Run設定の「アラート」→「Connect IQ」→「Runmity」をオンにします。機種によっては「アラート設定」内に表示されます。

Every run

通常の利用方法

初回設定後は、センサー検索を繰り返す必要はありません。

  1. 双方のウォッチで通常のRunアクティビティを開きます。
  2. Runを開始して走ります。
  3. 相互検知が成立すると、振動とハイタッチアニメーションが表示されます。

同じ相手には、そのラン中は再通知しません。Auto Pause中のウォッチはGreetingの対象になりません。

Troubleshooting

うまく動かないとき

センサーが見つからない

もう1台でRunmityをRun画面に追加し、先にRunを開始してください。その状態で登録側の「Connect IQ」または「すべて検索」を最大30秒実行します。

振動するが画面が出ない

Run設定の「アラート」または「アラート設定」から、Connect IQのRunmityをオンにしてください。

停止中に反応しない

Auto Pause中はGreeting対象外です。実走するか、室内で確認するときだけAuto Pauseをオフにしてください。

同じ相手に2回目が出ない

仕様どおりです。同じ相手への通知は1回のランにつき1回です。再確認するときは双方で新しいRunアクティビティを開始してください。

English quick guide

Setup and everyday use

Install Runmity on both supported watches and add it to a one-field data screen in the native Run activity.

One-time sensor registration is required on: Forerunner 70, 165 series, 170 series, 255 series, 265 series, 570 series, 955 series, 965, and 970. Start Runmity on a second watch first, then open Sensors & Accessories → Add New → Connect IQ (or Search All) and select “Runmity Nearby.”

No sensor registration is required on: Forerunner 55, 245 series, 745, and 945 series.

Enable Runmity under Run Settings → Alerts → Connect IQ. After setup, simply start the normal Run activity on both watches. Sensor search does not need to be repeated. Watches in Auto Pause are not eligible for a greeting.

No account

Runmityの動作にアカウント、スマートフォン、位置情報、インターネット接続は使用しません。

Activity-scoped

匿名の短期IDはアクティビティごとに生成し、ラン終了時に破棄します。

Local stats

対応端末では日別のGreetingイベント数、ストリーク、累計だけをウォッチ内に保存します。

Safety and expectations

振動と表示は任意の挨拶の合図です。相手の身元、正確な距離、安全、物理的なハイタッチの成立を示すものではありません。周囲と走路の安全を優先し、反応が難しい場合は通知を無視してください。

The vibration and artwork are optional greeting cues. They do not identify another person or guarantee distance, safety, or physical contact. Always prioritize your route and surroundings.
